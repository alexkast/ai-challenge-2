# ai-challenge-2.0

Company Internal AI Challenge 2.0

---

## Tasks

### task-1 — Leaderboard Portal

A leaderboard web application built with React and TypeScript. Displays participant rankings and scores for the challenge.

**Stack:** React · TypeScript · Vite

---

### task-2 — Gather: Event Hosting Platform

A full-featured community event platform covering the complete event lifecycle: hosting, discovery, RSVP with waitlist management, venue check-in, attendee gallery, and feedback. Deployed and live.

**Live:** https://tiny-cat-43667f.netlify.app

**Stack:** React · TypeScript · Vite · Tailwind CSS · Supabase · Netlify

---

### task-3 — AI Learning Assistant (Telegram Bot)

An AI-powered learning assistant delivered as a Telegram bot. Users submit any article URL and receive an intelligent summary followed by an interactive quiz to test retention.

**Bot:** [@ai_ak_learn_bot](https://t.me/ai_ak_learn_bot)

**Stack:** n8n · Telegram Bot API · OpenAI API

---

### task-4 — ATC MCP Server

A Model Context Protocol server that exposes an Air Traffic Control scheduling system to AI assistants. Accepts flight submissions, assigns runways and gates using a priority-based greedy algorithm with dependency support, and surfaces results through MCP tools and resources.

**Stack:** Python 3.11+ · MCP SDK · Pydantic
